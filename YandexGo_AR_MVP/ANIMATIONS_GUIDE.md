1. Распакуйте архив в отдельную папку. Запускайте эту папку тем же способом, которым у вас заработала версия live.

## Размер и положение GIF

Откройте animation-config.js:

```js
export const animations = {
  throttle: {
    src: './assets/animations/gas.gif',
    width: 230,
    height: 200,
    offsetX: 0,
    offsetY: -115
  },
  brake: {
    src: './assets/animations/brake.gif',
    width: 180,
    height: 192,
    offsetX: 0,
    offsetY: -110
  }
};
```

width/height — размер области GIF в координатах мишени 1120×1000. На телефоне размер меняется вместе с масштабом мишени. object-fit: contain сохраняет пропорции. Задавайте обе величины пропорционально, чтобы было проще предсказать видимый размер.
Для газа ширине 276 соответствует высота 240; для тормоза ширине 240 — высота 256.

offsetX: + вправо, − влево. offsetY: + вниз, − вверх. Отсчитываются от 3D-метки до центра GIF.
Выбранные положения находятся над деталями. Проверьте на вашем ракурсе и подправьте: положение текста внутри самого GIF также влияет на визуальный результат.
Если увеличить картинку, может понадобиться сильнее сдвинуть её вверх. Слишком большой сдвиг за пределы мишени/экрана обрежет анимацию.

После сохранения обновите страницу телефона. Если виден старый файл, измените имя GIF и src либо добавьте к пути `?v=2`, например `gas.gif?v=2`, затем обновите страницу. При изменении JS надёжнее закрыть вкладку и очистить кэш сайта/выполнить перезагрузку без кэша.

## Добавить или заменить ещё одну анимацию

1. Скопируйте GIF в assets/animations/. Лучше простое имя латиницей без пробелов.
2. В animation-config.js добавьте объект с ключом шага; перед следующей записью нужна запятая.
3. Пример для переднего колеса:

```js
'front-wheel': {
  src: './assets/animations/front-wheel.gif',
  width: 200,
  height: 200,
  offsetX: 0,
  offsetY: -100
}
```

Это запись ВНУТРИ существующего объекта animations, а не второй export.
Ключи: throttle, brake, handlebar, 'foot-left', 'foot-right', 'front-wheel', 'rear-wheel', 'rear-brake'. Ключи с дефисом заключайте в кавычки.
MP4/WebM подключаются аналогично; видео воспроизводится без звука и по кругу, если кодек поддерживается устройством.
Скорость GIF задаётся длительностями кадров внутри GIF. Параметр speed ниже меняет только встроенные эффекты. Для изменения скорости GIF нужен повторный экспорт; в данных файлах кадры идут по 100 мс.

## Вернуть встроенную стрелку вместо GIF

В animation-config.js удалите объект нужного шага или замените его на null:

```js
export const animations = {
  throttle: null,
  brake: null
};
```

Теперь на обоих шагах снова будут стрелки и кружки. Для остальных шагов отсутствие записи тоже означает встроенную анимацию.
Пока GIF загружается или если её файл не найден, проект показывает встроенный эффект.

## Менять стрелочки и кружочки без сложного кода

Откройте новый effect-config.js. В effectDefaults находятся общие настройки. В effectOverrides — индивидуальные. Пример замены effectOverrides:

```js
export const effectOverrides = {
  throttle: {
    scale: 1.5,
    speed: 0.7,
    color: '#00ff88',
    showRings: false,
    offsetX: 0,
    offsetY: -10
  },
  brake: {
    scale: 1.3,
    speed: 1,
    ringRadius: 20,
    color: '#ff5533'
  }
};
```

| Параметр | Значение |
| --- | --- |
| scale | 1 — исходный размер; 1.5 — в полтора раза больше; положительное число |
| speed | 1 — обычная скорость; 0.5 — вдвое медленнее; 2 — вдвое быстрее; 0 — остановка |
| color | Цвет HEX, например #ff5533; null — цвет из marker-config.js |
| showRings | false скрывает центральные круги и точку; собственная вращающаяся дуга колеса остаётся |
| ringRadius | Радиус внутреннего круга; исходно 15, задавайте положительное число |
| offsetX / offsetY | Смещение всего встроенного эффекта вправо/вниз; отрицательное — влево/вверх |

Эти настройки не меняют подключённую GIF. Чтобы увидеть результат на газе/тормозе в уроке, сначала отключите GIF записью null. В animation-preview.html встроенные эффекты показаны отдельно и доступны для сравнения даже при подключённых GIF.

## Изменить форму/направление стрелки

Файл effects.js содержит сами рисунки. Функция arrow(ctx, start, end, width) рисует стрелку от start к end, width — толщина линии.
В case 'throttle' есть:

```js
arrow(ctx, [36, -52 + shift], [19, -16 + shift]);
```

Координаты считаются от метки: X вправо, Y вниз. Первые две координаты — начало, вторые — наконечник. Поменяйте их местами, чтобы развернуть стрелку. Например, толщина 6:

```js
arrow(ctx, [19, -16 + shift], [36, -52 + shift], 6);
```

shift задаёт движение туда-обратно. Число 12 в `const shift = phase * 12` — амплитуда для газа. Для тормоза свой блок case 'brake', амплитуда 11. Тексты урока, последовательность и базовые цвета — marker-config.js.
