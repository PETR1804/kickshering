Инструкция для запуска проекта:
1. Распакуйте архив и откройте папку `YandexGo_AR_MVP` в VS Code.
2. Откройте «Терминал → Новый терминал». Убедитесь, что в этой папке лежит `server.py`.
3. Запустите:

```sh
python server.py --port 8000
```

Если Windows не находит python, используйте `py server.py --port 8000`; на macOS/Linux можно `python3 server.py --port 8000`.
Python 3.10+; дополнительных Python-пакетов не требуется.
Оставьте терминал работающим. Для нового режима нужен именно server.py, а не расширение Live Server.

4. На ноутбуке откройте `http://localhost:8000/live.html`.
5. Дождитесь модели и сообщения «3D-точки передаются».
6. Во втором терминале запустите привычный LocalTunnel на порт **8000**. Если используете npx:

```sh
npx localtunnel --port 8000
```

7. На телефоне откройте полученный HTTPS-адрес, добавив `/ar.html?live=1`.
   Пример формы адреса: `https://ВАШ-АДРЕС/ar.html?live=1`.
   Если LocalTunnel покажет свою страницу допуска, сначала пройдите её.
8. Нажмите «Открыть камеру», разрешите доступ и наведите телефон на всю область модели с угловыми метками.
9. После «Самокат найден» нажмите «Начать обучение».


Для добовления анимаций перейдите в папку /assets/animations - далее будет указана другаяя инструкция, которая покажет куда вставлять ваши анимации
